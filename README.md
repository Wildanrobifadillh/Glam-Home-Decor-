# Glam House PVC Inventory Management System

Sistem manajemen operasional untuk toko Glam House PVC.

Project ini dibuat untuk membantu pengelolaan data barang, stok, penjualan, pembelian, retur, stock opname, laporan, payroll, akuntansi, dan monitoring owner melalui aplikasi mobile.

## Tech Stack

- Backend: Node.js, Express.js, Prisma, PostgreSQL
- Frontend Web: React.js, Vite, Tailwind CSS
- Mobile Owner: Flutter, Dart
- Database: PostgreSQL
- API Testing: Postman
